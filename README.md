# Calculadora

Calculadora simples em React + Vite (JavaScript puro, sem TypeScript).

Funcionalidades atuais: soma, subtração, multiplicação, divisão, ponto decimal, tratamento de divisão por zero (exibe "Erro" no display) e histórico com as últimas 3 operações exibido acima do display.

## Instalação

```bash
npm install
```

## Como rodar

```bash
npm run dev
```

Abra o endereço que o Vite indicar (normalmente http://localhost:5173). O servidor recarrega a página automaticamente (HMR) a cada alteração.

## Build de produção

```bash
npm run build
npm run preview
```

`npm run build` gera a pasta `dist/` e `npm run preview` serve esse build localmente.
